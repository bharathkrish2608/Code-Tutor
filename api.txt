# API Documentation

This document provides a comprehensive overview of the API used in the project, including the type of API, 
how it was created, and how it was integrated into the application.

---

## 1. Type of API

We used a **RESTful API** for this project. REST (Representational State Transfer) is a widely
 used architectural style for designing networked applications. It allows for communication between 
 the frontend and backend using HTTP methods.

### Key Features of RESTful API:
- Stateless: Each request from the client contains all the information needed to process the request.
- Resource-based: Resources are identified using URLs.
- Supports standard HTTP methods:
  - **GET**: Retrieve data.
  - **POST**: Create new data.
  - **PUT/PATCH**: Update existing data.
  - **DELETE**: Remove data.

## 2. Creating the API

The API was created using **Django REST Framework (DRF)**, a powerful and flexible toolkit for building Web APIs in Python.

### Steps to Create the API:

1. **Install Django REST Framework**:
   - Add the following to the `requirements.txt` file:
     ```
     djangorestframework
     ```
   - Install the dependencies:
     ```bash
     pip install -r requirements.txt
     ```

2. **Add DRF to Installed Apps**:
   - Open `config/settings.py` and add `'rest_framework'` to the `INSTALLED_APPS` list:
     ```python
     INSTALLED_APPS = [
         ...
         'rest_framework',
     ]
     ```

3. **Define Models**:
   - Open `backend/api/models.py` and define the data models. For example:
     ```python
     from django.db import models

     class Item(models.Model):
         name = models.CharField(max_length=100)
         description = models.TextField()
         created_at = models.DateTimeField(auto_now_add=True)

         def __str__(self):
             return self.name
     ```

4. **Create Serializers**:
   - Serializers convert complex data types (like Django models) into JSON and vice versa.
   - Open `backend/api/serializers.py` and create a serializer for the `Item` model:
     ```python
     from rest_framework import serializers
     from .models import Item

     class ItemSerializer(serializers.ModelSerializer):
         class Meta:
             model = Item
             fields = '__all__'
     ```

5. **Create Views**:
   - Views handle the logic for processing API requests.
   - Open `backend/api/views.py` and create views for the `Item` model:
     ```python
     from rest_framework import viewsets
     from .models import Item
     from .serializers import ItemSerializer

     class ItemViewSet(viewsets.ModelViewSet):
         queryset = Item.objects.all()
         serializer_class = ItemSerializer
     ```

6. **Define URLs**:
   - Open `backend/api/urls.py` and define the API endpoints:
     ```python
     from django.urls import path, include
     from rest_framework.routers import DefaultRouter
     from .views import ItemViewSet

     router = DefaultRouter()
     router.register(r'items', ItemViewSet)

     urlpatterns = [
         path('', include(router.urls)),
     ]
     ```

7. **Include API URLs in the Project**:
   - Open `backend/config/urls.py` and include the API URLs:
     ```python
     from django.contrib import admin
     from django.urls import path, include

     urlpatterns = [
         path('admin/', admin.site.urls),
         path('api/', include('api.urls')),
     ]
     ```

## 3. Integrating the API with the Frontend

The frontend communicates with the backend API using **HTTP requests**. We used the `fetch` API in JavaScript to make these requests.

### Steps to Integrate:

1. **Set Up the API Base URL**:
   - Open `frontend/src/services/api.js` and define the base URL for the API:
     ```javascript
     const API_BASE_URL = 'http://localhost:8000/api';

     export default API_BASE_URL;
     ```

2. **Create API Service Functions**:
   - To interact with the API endpoints, we need to create service functions. These functions will handle the communication between the frontend and the backend.

   ### Example Service Functions:
   ```javascript
   import API_BASE_URL from './api';

   // Function to fetch all items from the API
   export async function fetchItems() {
       // Send a GET request to the /items/ endpoint
       const response = await fetch(`${API_BASE_URL}/items/`);

       // Check if the response is successful
       if (!response.ok) {
           throw new Error('Failed to fetch items'); // Throw an error if the request fails
       }

       // Parse and return the JSON data from the response
       return await response.json();
   }

   // Function to create a new item in the API
   export async function createItem(data) {
       // Send a POST request to the /items/ endpoint with the item data
       const response = await fetch(`${API_BASE_URL}/items/`, {
           method: 'POST', // Specify the HTTP method as POST
           headers: {
               'Content-Type': 'application/json', // Indicate that the request body is in JSON format
           },
           body: JSON.stringify(data), // Convert the data object to a JSON string
       });

       // Check if the response is successful
       if (!response.ok) {
           throw new Error('Failed to create item'); // Throw an error if the request fails
       }

       // Parse and return the JSON data for the newly created item
       return await response.json();
   }
   ```

   ### Explanation:
   - **`fetchItems` Function**:
     - This function sends a `GET` request to the `/items/` endpoint to retrieve a list of items from the backend.
     - If the request is successful, it parses the JSON response and returns the data.
     - If the request fails (e.g., due to a network error or server issue), it throws an error with a descriptive message.

   - **`createItem` Function**:
     - This function sends a `POST` request to the `/items/` endpoint to create a new item in the backend.
     - The `Content-Type` header is set to `application/json` to indicate that the request body contains JSON data.
     - The `data` object is converted to a JSON string using `JSON.stringify` and included in the request body.
     - If the request is successful, it parses the JSON response and returns the newly created item.
     - If the request fails, it throws an error with a descriptive message.

3. **Use the API in React Components**:
   - To use the service functions in a React application, we can create a component that interacts with the API.

   ### Example React Component:
   ```javascript
   import React, { useEffect, useState } from 'react';
   import { fetchItems, createItem } from '../services/api';

   function ItemList() {
       // State to store the list of items
       const [items, setItems] = useState([]);

       // State to store the value of the new item input field
       const [newItem, setNewItem] = useState('');

       // Fetch the list of items when the component is first rendered
       useEffect(() => {
           async function loadItems() {
               try {
                   const data = await fetchItems(); // Call the fetchItems function
                   setItems(data); // Update the items state with the retrieved data
               } catch (error) {
                   console.error(error); // Log any errors to the console
               }
           }
           loadItems();
       }, []); // The empty dependency array ensures this runs only once

       // Function to handle adding a new item
       async function handleAddItem() {
           try {
               const item = await createItem({ name: newItem }); // Call the createItem function
               setItems([...items, item]); // Add the new item to the items state
               setNewItem(''); // Clear the input field
           } catch (error) {
               console.error(error); // Log any errors to the console
           }
       }

       return (
           <div>
               <h1>Item List</h1>
               <ul>
                   {/* Render the list of items */}
                   {items.map((item) => (
                       <li key={item.id}>{item.name}</li>
                   ))}
               </ul>
               <input
                   type="text"
                   value={newItem}
                   onChange={(e) => setNewItem(e.target.value)} // Update the newItem state as the user types
               />
               <button onClick={handleAddItem}>Add Item</button>
           </div>
       );
   }

   export default ItemList;
   ```

   ### Explanation:
   - **State Management**:
     - The `items` state holds the list of items retrieved from the API.
     - The `newItem` state holds the value of the input field for adding a new item.

   - **Fetching Items**:
     - The `useEffect` hook is used to fetch the list of items when the component is first rendered.
     - The `fetchItems` function is called, and the retrieved data is stored in the `items` state.

   - **Adding a New Item**:
     - The `handleAddItem` function is triggered when the "Add Item" button is clicked.
     - It calls the `createItem` function to send the new item data to the API.
     - The newly created item is added to the `items` state, and the input field is cleared.

   - **Rendering the UI**:
     - The component renders a list of items using the `map` function.
     - It also includes an input field and a button for adding new items.

## 4. Testing the API

We used **Postman** to test the API endpoints during development. Postman allows you to send HTTP requests and view the responses.

### Steps:
1. Open Postman and create a new request.
2. Set the request method (e.g., GET, POST) and URL (e.g., `http://localhost:8000/api/items/`).
3. Add any required headers or body data.
4. Send the request and verify the response.
