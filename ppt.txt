SLIDE 1: PROJECT METHODOLOGY
--------------------------------------------------------------------------------
* 6-Week Structured Development Lifecycle:
  - Phase 1 (Foundation): Environment setup using Django (Backend) and React/Vite (Frontend). Established database schemas and core API boilerplate.
  - Phase 2 (Intelligence): Developed the AI Analyzer engine in 'analyzer.py'. Implemented Google Gemini 2.5-flash and crafted specialized "System Prompts" to define the "Tutor Persona."
  - Phase 3 (UI/UX Design): Designed a modern "SaaS / Builder" interface. Focused on glassmorphism, soft pastel gradients, and developer-centric typography (Inter & JetBrains Mono).
  - Phase 4 (Integration): Connected the decoupled layers using Axios and RESTful API endpoints. Configured CORS for secure cross-origin communication.
  - Phase 5 (Testing & Quality): Conducted rigorous unit testing, stress testing (malformed code/large payloads), and cross-device responsiveness checks.
  - Phase 6 (Finalization): Performance tuning (3-5s response time optimization) and comprehensive documentation of the entire codebase.

* Persona-Driven AI Strategy:
  - Iterative Prompt Engineering: Refined the AI's response logic to prioritize pedagogical value over simple code correction.
  - Structured Feedback Loop: Mandated a consistent 6-section response (Analysis -> Mistakes -> Explanation -> Correction -> Concept -> Practice).
  - Beginner-Centric Logic: Tuned the engine to avoid jargon and use relatable analogies for explaining complex programming concepts.


SLIDE 2: SYSTEM ARCHITECTURE
--------------------------------------------------------------------------------
* Decoupled Client-Server Architecture:
  - Frontend (Client): React 19 + Vite + Tailwind CSS for a modern, responsive UI.
  - Backend (Server): Django 5.0 + Django REST Framework (DRF) for API management.
* AI Intelligence Layer:
  - Powered by Google Gemini 2.5-flash model.
  - Implements a structured 6-section feedback loop (Analysis, Mistakes, Explanations, Corrected Code, Concepts, Practice).
* End-to-End Data Flow:
  1. User Submission: Code captured via the React-based CodeEditor component.
  2. API Request: Frontend sends an asynchronous POST request via Axios to the Django backend.
  3. AI Processing: Backend triggers the CodeAnalyzer class, which queries Gemini AI with the user's code and a system persona prompt.
  4. Structured Response: AI returns JSON-formatted feedback, which is parsed and rendered in the UI using Markdown and Syntax Highlighting.


SLIDE 3: DESIGN AND AESTHETICS
--------------------------------------------------------------------------------
* Modern AI SaaS UI Philosophy:
  - Theme: "Code-First Builder" aesthetic with a clean, professional dark mode.
  - Visual Language: Heavy use of glassmorphism (frosted glass effects), soft mesh gradients, and subtle drop shadows.
  - Interactive Micro-animations: Smooth transitions for loading states and hover effects for interactive components.
* Design Tokens:
  - Color Palette: Deep Slate backgrounds, Azure/Electric Blue accents, and Pastel Green for success/tutorial notes.
  - Typography: Inter (Interface), JetBrains Mono (Code), and Caveat (Editorial flourishes).

SLIDE 4: STEP-BY-STEP IMPLEMENTATION
--------------------------------------------------------------------------------
1. Scaffolding & Setup:
   - Initialized Django REST backend and React/Vite frontend in a mono-repo structure.
   - Configured environment variables (.env) and CORS headers for secure integration.
2. Engine Development (The Brain):
   - Created 'analyzer.py' to bridge Django with Google Gemini API.
   - Engineered the "Tutor Persona" system prompt for pedagogical feedback.
3. Component Engineering:
   - Built the 'CodeEditor' using react-simple-code-editor with syntax highlighting support.
   - Developed the 'FeedbackDisplay' to parse AI Markdown responses in real-time.
4. Full-Stack Integration:
   - Established Axios service layers to handle POST requests from React to Django.
   - Implemented global state management for 'Submission -> Analysis -> Result' flow.
5. UI Polishing & Optimization:
   - Applied CSS-in-JS and Tailwind tokens for a responsive, premium SaaS look.
   - Optimized response latency and handled edge-case error states (timeouts, malformed code).
