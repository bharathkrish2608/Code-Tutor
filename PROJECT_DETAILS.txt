================================================================================
                         PROJECT: AI CODING TUTOR
================================================================================

1. PROJECT OVERVIEW
-------------------
AI Coding Tutor is a full-stack web application designed to help beginners improve 
their coding skills. Users can submit their code (primarily Python) to receive 
expert, structured feedback generated by AI. The application identifies mistakes, 
provides beginner-friendly explanations, offers corrected code snippets, and 
suggests practice exercises to reinforce learning.

The interface is built with a modern "SaaS / Builder UI" aesthetic, featuring 
glassmorphism elements, soft gradients, and a highly responsive design.

2. TECHNOLOGY STACK
-------------------
BACKEND (Python/Django):
- Core Framework: Django 5.0
- API Framework: Django REST Framework (DRF)
- AI Engine: Google Gemini AI (gemini-2.5-flash)
- Environment Management: python-dotenv
- Security: django-cors-headers (allowing communication with Vite frontend)

FRONTEND (JavaScript/React):
- Build Tool: Vite
- UI Library: React 19
- Styling: Tailwind CSS (modern SaaS design tokens)
- Markdown Rendering: react-markdown
- Syntax Highlighting: react-syntax-highlighter (Prism)
- Icons/UI Elements: Lucide React (standard in SaaS UIs)

3. PROJECT ARCHITECTURE & DATA FLOW
-----------------------------------
A to Z Process Flow:
A. The user types or pastes code into the "CodeEditor" component on the React frontend.
B. When the "Analyze" button is clicked, the frontend sends an asynchronous POST request 
   via fetch to the Django API endpoint (`/api/analyze/`).
C. The Django `AnalyzeCodeView` receives the request and passes the code to the 
   `CodeAnalyzer` class.
D. The `CodeAnalyzer` initializes the Gemini AI model and sends the user's code 
   along with a specialized "System Prompt" (defining the persona of a Tutor).
E. Gemini AI generates a structured response with 6 specific sections:
   1. Code Analysis
   2. Mistakes Found
   3. Beginner Explanation
   4. Corrected Code
   5. Key Concept
   6. Practice Exercises
F. The backend returns this response as JSON data to the React frontend.
G. The frontend stores this result in state and renders it through the 
   "FeedbackDisplay" component using Markdown and Syntax Highlighting.

4. CORE DIRECTORY & FILE BREAKDOWN
----------------------------------
/backend/
  api/
    - analyzer.py: The heart of the AI. Contains the CodeAnalyzer class and the 
      complex system prompt that defines the tutor's behavior and formatting rules.
    - views.py: Contains `AnalyzeCodeView`, the REST endpoint that handles the 
      incoming code and sends back the analysis.
    - urls.py: Defines the endpoint structure (e.g., `api/analyze/`).
  config/
    - settings.py: Backend configuration including CORS, Installed Apps, and Database.
  .env: Stores sensitive secrets like the `GEMINI_API_KEY`.

/frontend/
  src/
    - App.jsx: The main application container. Manages application state (code, 
      result, loading status) and the overall layout.
    - components/
      - Header.jsx: Modern, glassmorphism-styled navigation bar.
      - CodeEditor.jsx: A clean interface for users to input their code.
      - FeedbackDisplay.jsx: Uses `react-markdown` and `react-syntax-highlighter` 
        to present the AI's feedback beautifully.
    - services/
      - api.js: Centralized API logic for communicating with the Django backend.
    - index.css: Custom Tailwind configuration and modern UI CSS tokens (gradients, 
      animations, glassmorphism).

5. ARTIFICIAL INTELLIGENCE LOGIC
--------------------------------
The tutor utilizes the "gemini-2.5-flash" model. A specific "persona" is enforced 
via the system prompt:
- Focuses on being beginner-friendly.
- Avoids complex technical jargon.
- Provides step-by-step explanations.
- Forces a 6-section structure for consistency.
- Generates practice exercises of increasing difficulty to ensure comprehension.

6. HOW TO SET UP AND RUN
------------------------
BACKEND:
1. Navigate to /backend directory.
2. Install dependencies: `pip install -r requirements.txt`.
3. Create a `.env` file and add: `GEMINI_API_KEY=your_key_here`.
4. Run the server: `python manage.py runserver`.

FRONTEND:
1. Navigate to /frontend directory.
2. Install dependencies: `npm install`.
3. Start the development server: `npm run dev`.
4. Open the provided local URL in your browser.
