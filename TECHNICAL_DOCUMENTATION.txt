2. PROBLEM STATEMENT
--------------------
Learning to code can be an isolating and frustrating experience for beginners. 
Traditional compilers and linters provide technical error messages that are 
often cryptic and discouraging. Students frequently find themselves:
- Stuck on syntax errors without understanding the underlying logic.
- Fixing code without learning the core concepts behind the fix.
- Lacking personalized practice exercises tailored to their specific mistakes.
- Needing immediate feedback when human tutors are unavailable.

AI Coding Tutor addresses these gaps by providing a "pedagogical bridge" between 
raw code and conceptual understanding.

3. METHODOLOGY
--------------
The project followed a structured 6-week development lifecycle:
- Week 1: Environment setup and core Django/React boilerplate.
- Week 2: Development of the AI Analyzer engine and prompt engineering.
- Week 3: UI/UX design focusing on a "SaaS / Builder" aesthetic.
- Week 4: Integration of frontend and backend via RESTful APIs.
- Week 5: Rigorous testing, handling edge cases, and performance tuning.
- Week 6: Final documentation, bug hunting, and production readiness.

The development approach prioritized "Persona-Driven AI," where the system prompt 
was iteratively refined to ensure the AI acts as a patient teacher rather than 
just a code corrector.

4. SYSTEM ARCHITECTURE
----------------------
The application uses a decoupled client-server architecture:

A. Frontend (Client Layer):
   - React 19 handles the UI and application state.
   - Vite ensures fast builds and a smooth developer experience.
   - Tailwind CSS provides a modern, responsive design system.
   - components/CodeEditor: Captures user input.
   - components/FeedbackDisplay: Renders AI response using Markdown.

B. Backend (API Layer):
   - Django REST Framework (DRF) manages the API endpoints.
   - AnalyzeCodeView: Processes incoming POST requests.
   - CodeAnalyzer: The logic layer that communicates with Google's Gemini API.

C. AI Engine (Intelligence Layer):
   - Google Gemini 2.5-flash model processes code snippets.
   - System Prompts enforce a 6-section feedback structure:
     1. Analysis | 2. Mistakes | 3. Explanations | 4. Corrected Code | 5. Concepts | 6. Practice.

5. PHASED IMPLEMENTATION ROADMAP
-------------------------------
The project was executed in five distinct phases to ensure stability and quality:

PHASE 1: Project Scaffolding (The Skeleton)
- Initialized Django project and React/Vite frontend in parallel.
- Configured CORS and environment variable security to allow frontend-backend communication.
- established a centralized 'config/' directory for backend settings and 'src/services/' for frontend API logic.

PHASE 2: Backend Logic & AI Engine (The Brain)
- Built the 'analyzer.py' logic layer, integrating Google Gemini 2.5-flash via API.
- Prompt Engineering: Iteratively refined a 500-word system prompt to ensure the AI maintained a "Tutor Persona" (encouraging, clear, and structured).
- Developed DRF views to handle incoming code snippets and serialize analysis results.

PHASE 3: Component Engineering (The Interface)
- Developed 'CodeEditor.jsx' focusing on performance and syntax highlighting using 'react-simple-code-editor'.
- Built 'FeedbackDisplay.jsx' with 'react-markdown' to render the AI's complex structured output (code blocks, bullet points, etc.).
- Integrated 'Lucide React' icons for a professional SaaS visual language.

PHASE 4: Full-Stack Integration (The Connection)
- Implemented Axios-based service handlers to manage the asynchronous data flow between the React client and Django server.
- Built a robust state management system in 'App.jsx' to track 'Submitting', 'Analyzing', and 'Error' states.
- Handled edge cases including network timeouts and empty user submissions.

PHASE 5: Visual Polishing & UX Optimization (The Skin)
- Applied the "SaaS / Builder" design system: glassmorphism, soft gradients, and custom scrollbars.
- Optimized UI responsiveness for mobile and desktop views using Tailwind CSS.
- Conducted a final bug hunt to ensure 100% reliability in feedback parsing.
