# Step-by-Step Guide to Creating the Frontend

This guide will walk you through the process of creating a simple frontend for a web application. We will create a heading, a text box, and a display UI using React.js. This explanation is tailored for beginners, so we will cover everything in detail.

---

## 1. Setting Up the Frontend

### Tools and Technologies Used:
- **React.js**: A JavaScript library for building user interfaces.
- **HTML**: For structuring the content.
- **CSS**: For styling the components.

### Steps to Set Up React:
1. **Install Node.js**: Make sure you have Node.js installed on your computer. You can download it from [Node.js official website](https://nodejs.org/).
2. **Create a React App**:
   - Open your terminal and navigate to the folder where you want to create your project.
   - Run the following command:
     ```bash
     npx create-react-app my-app
     ```
   - Replace `my-app` with your desired project name.
3. **Navigate to the Project Folder**:
   ```bash
   cd my-app
   ```
4. **Start the Development Server**:
   ```bash
   npm start
   ```
   This will open your app in the browser at `http://localhost:3000`.

---

## 2. Creating the Heading "Coding Tutor"

### Steps:
1. Open the `src/App.jsx` file in your React project.
2. Replace the existing code with the following:
   ```jsx
   import React from 'react';
   import './App.css';

   function App() {
     return (
       <div className="App">
         <header className="App-header">
           <h1>Coding Tutor</h1>
         </header>
       </div>
     );
   }

   export default App;
   ```
3. **Explanation**:
   - `h1` is an HTML tag used for the main heading.
   - The `header` tag wraps the heading to give it a semantic structure.

4. **Styling the Heading**:
   - Open the `src/App.css` file.
   - Add the following CSS:
     ```css
     .App-header {
       background-color: #282c34;
       padding: 20px;
       text-align: center;
     }

     .App-header h1 {
       color: #61dafb;
       font-size: 3rem;
     }
     ```
   - This will style the heading with a blue color and center it on the page.

---

## 3. Creating the Text Box

### Steps:
1. Modify the `App.jsx` file to include an input box:
   ```jsx
   import React, { useState } from 'react';
   import './App.css';

   function App() {
     const [inputValue, setInputValue] = useState('');

     return (
       <div className="App">
         <header className="App-header">
           <h1>Coding Tutor</h1>
           <input
             type="text"
             placeholder="Type something..."
             value={inputValue}
             onChange={(e) => setInputValue(e.target.value)}
             className="text-box"
           />
         </header>
       </div>
     );
   }

   export default App;
   ```
2. **Explanation**:
   - `useState` is a React hook that allows us to manage the state of the input box.
   - The `input` tag creates a text box.
   - The `onChange` event updates the state whenever the user types something.

3. **Styling the Text Box**:
   - Add the following CSS to `App.css`:
     ```css
     .text-box {
       margin-top: 20px;
       padding: 10px;
       font-size: 1rem;
       border: 2px solid #61dafb;
       border-radius: 5px;
     }

     .text-box:focus {
       outline: none;
       border-color: #21a0f6;
     }
     ```
   - This will style the text box with a border and rounded corners.

---

## 4. Creating the Display UI

### Steps:
1. Modify the `App.jsx` file to display the text entered in the text box:
   ```jsx
   import React, { useState } from 'react';
   import './App.css';

   function App() {
     const [inputValue, setInputValue] = useState('');

     return (
       <div className="App">
         <header className="App-header">
           <h1>Coding Tutor</h1>
           <input
             type="text"
             placeholder="Type something..."
             value={inputValue}
             onChange={(e) => setInputValue(e.target.value)}
             className="text-box"
           />
           <p className="display-text">{inputValue}</p>
         </header>
       </div>
     );
   }

   export default App;
   ```
2. **Explanation**:
   - The `p` tag is used to display the text entered in the text box.
   - `{inputValue}` dynamically updates the displayed text as the user types.

3. **Styling the Display UI**:
   - Add the following CSS to `App.css`:
     ```css
     .display-text {
       margin-top: 20px;
       color: #ffffff;
       font-size: 1.5rem;
     }
     ```
   - This will style the displayed text with a white color and larger font size.

---

## 5. Achieving the Notebook Theme

To give the application a notebook-like theme, we can use CSS to style the background, borders, and layout to resemble a notebook page.

### Steps:
1. **Styling the Background**:
   - Add the following CSS to `App.css`:
     ```css
     .App {
       background-color: #f5f5f5;
       min-height: 100vh;
       display: flex;
       justify-content: center;
       align-items: center;
       font-family: 'Courier New', Courier, monospace;
     }

     .App-header {
       background: #ffffff;
       border: 1px solid #ddd;
       box-shadow: 0 4px 6px rgba(0, 0, 0, 0.1);
       padding: 20px;
       border-radius: 10px;
       width: 90%;
       max-width: 600px;
     }

     .App-header h1 {
       font-family: 'Georgia', serif;
       font-size: 2.5rem;
       color: #333;
     }
     ```

2. **Adding Notebook Lines**:
   - Add the following CSS to create horizontal lines like a notebook:
     ```css
     .App-header {
       background: repeating-linear-gradient(
         white,
         white 24px,
         #eaeaea 25px
       );
     }
     ```
   - This creates a subtle lined background for the notebook effect.

3. **Final Touches**:
   - Ensure the text box and displayed text align well with the notebook theme by keeping the font consistent and using soft colors.

---

## 6. Final Output

When you run the app, you will see:
- A heading that says "Coding Tutor" styled like a notebook title.
- A text box where you can type something.
- The text you type will be displayed below the text box in real-time.
- The entire app will have a notebook-like theme with lined paper and a clean layout.

Congratulations! You have successfully created a simple frontend using React.js with a notebook-like theme. This is a great starting point for building more creative user interfaces.
