LinkedIn Post Caption:

For my internship project, I built AI Coding Tutor—a full-stack web application designed to help beginner programmers actually understand their code errors instead of getting stuck or blind copy-pasting. When you paste broken Python code into the app, it runs an AI analysis through Google's Gemini API and returns structured feedback: an analysis of your code, what went wrong, a plain-English explanation, corrected code, the core programming concept, and two custom practice exercises to test your understanding. I built the client with React 19, Vite, and Tailwind CSS, and connected it to a Django REST Framework backend. The complete project is live and documented on GitHub at github.com/bharathkrish2608/ai-coding-tutor—check it out and let me know your thoughts!
